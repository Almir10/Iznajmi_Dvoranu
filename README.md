Ova aplikacija omogućava korisnicima da pretražuju, rezervišu, i upravljaju dvoranama za događaje. Aplikacija je razvijena s ciljem olakšavanja procesa iznajmljivanja dvorana, pružajući intuitivno korisničko sučelje i efikasno upravljanje rezervacijama.

Tehnologije korišćene u razvoju

Back-end:
 - Node.js
- Express.js
  
Front-end:
 -  HTML5
- CSS3
 -  JavaScript
  - Bootstrap (minimalno za styling)
  
Baza podataka:
  - MySQL


/////////

**Funkcionalnosti aplikacije**

**Za klijente (korisnike):**
  Registracija i prijava.
  Pretraga dvorana prema lokaciji, dostupnosti i ceni.
  Rezervacija dvorane za određeni datum.
  
**Za vlasnike dvorana:**
  Dodavanje novih dvorana sa detaljima (opis, cena, lokacija).
  Pregled i upravljanje rezervacijama:
  Prihvatanje ili odbijanje rezervacija ukoliko je automatsko rezervisanje isključeno.
  Upravljanje dostupnošću dvorana po danima.
  
**Za administratore:**
  Upravljanje korisnicima (klijentima i vlasnicima).
  Upravljanje dvoranama (brisanje ili ažuriranje informacija).
  Pregled svih rezervacija.
